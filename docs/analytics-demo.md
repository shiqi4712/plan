# 运营后台 Demo

本地地址：`http://127.0.0.1:3001/admin/analytics`。

此页面展示固定模拟数据，不采集真实访客，不包含统计API或数据库。后台已加入服务端管理员登录；执行部署脚本后才会开放服务器后台路径。源码包包含Demo代码但不包含账号密码配置。

登录地址：`/admin/login`，管理员账号为 `shiqi`。密码的加盐scrypt哈希通过被Git忽略的`.env.local`中的`ADMIN_PASSWORD_HASH`配置，格式为`salt:hash`，用户名通过`ADMIN_USERNAME`配置；不在代码中保存明文密码。使用随机会话令牌和HttpOnly、SameSite=Lax Cookie，生产模式启用Secure。会话有效期8小时，退出后服务端失效。连续失败5次暂停登录1分钟。

当前Demo会话及失败计数在单进程内存中维护，重启后需重新登录；多实例生产部署前需改为共享会话与限流存储，并在服务器单独配置凭据。

支持日期范围、课线筛选、指标排序、课线详情、链接复制与CSV导出。关键指标下直接展示课线明细，不再展示趋势图。数据范围为北京时间2026-08-19至2026-09-17；“今天”对应演示基准日2026-09-17。

“删除当前数据”按当前日期和课线筛选删除模拟访问及其关联末页记录；在详情页仅删除该课线。确认框显示范围及条数。删除状态保存在本浏览器 localStorage，刷新后保留，并同步同源其他标签页；“恢复演示数据”会恢复所有已删除的模拟记录。真实服务器数据与课线链接不受影响。

UV按匿名浏览器标识在所选范围去重，全课线汇总跨课线去重。末页查阅要求前台可见并连续停留2秒，同一次进入只记一次，再次进入可重新计数；末页独立访客去重。末页到达率为末页独立访客/UV，不表示逐页读完或报名转化。上述规则在Demo中由模拟事件表达，正式采集仍需实现埋点。

核心文件：`components/AnalyticsDemo.tsx`、`lib/analytics-demo.ts`、`app/admin/analytics/analytics.css`。去重及筛选单元测试位于`tests/analytics-demo.test.ts`。
